# Faysal Portfolio

A responsive personal portfolio website built with HTML and CSS to showcase my profile, education, skills, and contact information.

## Live Demo
https://faysalahamed222.github.io/faysal-porfolio1/

## About This Project
This is a single-page personal portfolio website for Faysal Ahmed. It includes a hero section, navigation bar, about me section, education details, and contact links. The layout is designed to be responsive across mobile, tablet, and desktop devices.

## Features
- Responsive design for mobile, tablet, and desktop
- Clean personal branding layout
- About me section
- Education timeline details
- CV download button
- Hire me/contact link
- Modern hover effects and card styling

## Tech Stack
- HTML5
- CSS3
- Google Fonts

## Run Locally
1. Clone the repository:
```bash
git clone https://github.com/faysalahamed222/faysal-porfolio1.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

Or run a local server:
```bash
cd faysal-porfolio1
python3 -m http.server 8000
```

Then open:
```bash
http://localhost:8000
```
